# 实拍照片标注（ground truth）

这份文件记录每张照片里**实际**的手牌与副露，用来核对拍照识别的准确率。

**v2 — 已按你的复核意见修正。** 修改点见文末「修订记录」。

## 记号

| 花色 | 代号 | 例 |
|---|---|---|
| 萬 | `m` | `2m` = 二萬 |
| 筒 | `p` | `5p` = 五筒 |
| 條 | `s` | `8s` = 八條 |

- **手牌** = 自己手里没亮出来的牌
- **副露** = 已经碰/杠的牌，记作 `碰8s` / `明杠4s` / `暗杠3p`
- **张数校验** = 手牌张数 + 3 × 副露组数，合法值为 **13**（未摸牌）或 **14**（已摸牌）
- **实物张数** = 桌上真实摆着的牌数 = 13（或 14）+ 杠的组数（每个杠多一张）
- 桌子中央的弃牌堆、别人的牌**不计入**

### 这套牌容易认错的三个花色

| 牌 | 图案 | 易混 |
|---|---|---|
| **八筒** | 黑圈 **2 列 × 4 行 = 8 颗** | 低分辨率下整块黑圈很容易被数成 3×3 当成九筒。**这批照片里没有九筒。** |
| **七筒** | 上面 4 颗红 + 下面 **3 颗绿** | 与六筒只差下面一颗（六筒是 2 颗绿） |
| **八條** | 上下两个折线，像 `W` 叠 `M` | 是弯折的竹节，不是字母 |
| **七條** | 顶部 1 颗红竹节 + 下面两排各 3 颗 | — |
