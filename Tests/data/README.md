# 国标算番的官方对照数据

`mcr_oracle_cases.txt` —— 313 条「牌型 → 期望番种 / 总分」。

**期望值不是我们自己推的**，来自 **PyMahjongGB**（北大 Botzone 国标麻将比赛官方算番器，
逐字 vendor 了 ChineseOfficialMahjongHelper 的 mahjong-algorithm）。

生成方式：随机构造 12000 副合法和牌（4 面子 + 将，含吃/碰/明杠/暗杠，随机门风圈风），
两边分别算番，再按「番种覆盖」抽样——每个番种至少 3 例，共覆盖 59 个番种。

格式：`手牌|副露|和牌张|门风|圈风|总分|番种,番种,…`
- 手牌含和牌张；副露 `kind,牌`，kind ∈ chow(吃，写起始牌) / pung / ekong / ckong
- 门风、圈风为 1–4（东南西北），载入时减 1 转成引擎的 0 基
- 官方的「独听・嵌张 / 独听・单钓 / 独听・边张」对应我们的 坎张 / 单钓将 / 边张

`mcr_reference.md` —— 规则参照报告：81 番种表、五大计分原则原文（中文 + 官方英译）、
逐番种排除关系、20 个易错边界。每条标注了来源与可信度分级。
